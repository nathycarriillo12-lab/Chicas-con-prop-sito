# Soltería con Propósito 🌷

Sitio web de la comunidad cristiana **Soltería con Propósito**.

## Estructura

- `index.html`: contenido y secciones de la página principal.
- `css/style.css`: identidad visual y diseño responsive.
- `js/main.js`: menú móvil, año del pie de página y formulario de oración (abre la app de correo; no almacena datos).

## Publicar con GitHub Pages

1. Abre **Settings** en este repositorio.
2. En el menú lateral, entra en **Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)), guarda los cambios.
5. Espera a que GitHub Pages termine la publicación y muestre la URL.

## Notas antes de lanzar

- Revisar y reemplazar los enlaces de redes sociales provisionales.
- Para recibir peticiones directamente sin depender del correo predeterminado de cada visitante, conectar un servicio de formularios y revisar las consideraciones de privacidad.
- Se puede conectar un dominio propio más adelante.
